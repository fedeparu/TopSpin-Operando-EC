Operando companion

A TopSpin-style display workspace for linked electrochemical and NMR analysis.

InspectMove over either plot. Click to lock; Unlock hover resumes inspection.NavigateSelect an acquisition in the data browser, use the 1D dropdown or the arrow buttons.DisplaySwitch stacked, contour or map views. Ppm and time zoom remain linked.Pop outOpen a separate companion window with your current analysis.

Display commands

stack · contour · map
full · peak · reset
spectrum 12 · gain 1.2

linked · detail · browser · help

/ focuses the command line. 1 / 2 switch the linked and 1D workspaces. Home resets the display. Ctrl+S saves analysis.

This is an external companion prototype with TopSpin-inspired navigation. It is not an embedded Bruker window. Vendor processing commands and real instrument acquisition are unavailable here.
